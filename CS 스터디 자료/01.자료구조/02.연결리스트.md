# 02. 연결리스트 (Linked List)

> **학습 목표**
> - 노드와 포인터로 구성된 연결리스트의 구조를 그릴 수 있다.
> - 단일/이중/원형 연결리스트의 차이를 설명할 수 있다.
> - 배열과 연결리스트의 시간복잡도를 비교할 수 있다.

---

## 1. 개념

연결리스트는 **데이터와 다음 노드의 주소(포인터)를 가진 노드들이 줄줄이 연결된** 자료구조입니다. 배열과 달리 메모리상에서 연속될 필요가 없습니다.

```
head
 ↓
+------+---+    +------+---+    +------+------+
|  10  | ●-+--> |  20  | ●-+--> |  30  | null |
+------+---+    +------+---+    +------+------+
 data   next     data   next     data   next
```

- **head**: 첫 번째 노드를 가리키는 참조
- 마지막 노드의 next는 `null`

---

## 2. 종류

### 단일 연결리스트 (Singly)
- 각 노드가 **다음 노드만** 가리킵니다.
- 앞으로만 이동할 수 있습니다.

### 이중 연결리스트 (Doubly)
```
null <- [prev|10|next] <-> [prev|20|next] <-> [prev|30|next] -> null
```
- 각 노드가 **이전 노드와 다음 노드**를 모두 가리킵니다.
- 양방향 이동이 가능하고, 노드 참조만 있으면 O(1)에 삭제할 수 있습니다.
- 대신 포인터 하나만큼 메모리를 더 씁니다.
- Java의 `LinkedList`가 이중 연결리스트입니다.

### 원형 연결리스트 (Circular)
- 마지막 노드가 다시 head를 가리킵니다.
- 라운드 로빈 스케줄링처럼 순환하는 구조에 씁니다.

---

## 3. 연산 동작 원리

### 삽입 (노드 B 뒤에 X 삽입)
```
Before:  A -> B -> C
1) X.next = B.next      X -> C
2) B.next = X           A -> B -> X -> C
```
- **순서가 중요**합니다. 2)를 먼저 하면 C의 주소를 잃어버립니다.
- 위치(B)를 알고 있다면 포인터 2개만 바꾸므로 **O(1)** 입니다.

### 삭제 (B 삭제)
```
Before:  A -> B -> C
A.next = B.next         A -> C
```
- 단일 연결리스트에서는 **B의 이전 노드(A)를 알아야** 합니다. 모르면 처음부터 찾아야 하므로 O(n).
- 이중 연결리스트는 `B.prev`로 A를 바로 알 수 있으므로 O(1).

---

## 4. 배열과 비교

| 연산 | 배열 | 연결리스트 |
|---|---|---|
| i번째 접근 | **O(1)** | O(n) (head부터 따라가야 함) |
| 맨 앞 삽입/삭제 | O(n) | **O(1)** |
| 맨 뒤 삽입 | O(1)* | O(1) (tail 포인터 유지 시) |
| 중간 삽입/삭제 (위치를 알 때) | O(n) | **O(1)** |
| 중간 삽입/삭제 (위치를 찾아야 할 때) | O(n) | O(n) |
| 메모리 | 연속, 오버헤드 적음 | 분산, 노드마다 포인터 오버헤드 |
| 캐시 효율 | 좋음 | 나쁨 |

\* 동적 배열 기준 분할 상환 O(1)

> **주의**: "연결리스트는 삽입이 O(1)"이라는 말은 **삽입 위치를 이미 알고 있을 때**만 맞습니다. 인덱스 k에 삽입하려면 k번째까지 찾아가는 O(n)이 먼저 필요합니다.

## 5. Java 구현 (단일 연결리스트)

```java
public class MyLinkedList {
    private static class Node {
        int data;
        Node next;
        Node(int data) { this.data = data; }
    }

    private Node head;
    private int size;

    // 맨 앞 삽입 O(1)
    public void addFirst(int data) {
        Node node = new Node(data);
        node.next = head;
        head = node;
        size++;
    }

    // 맨 뒤 삽입 O(n) (tail 포인터가 없으므로)
    public void addLast(int data) {
        Node node = new Node(data);
        if (head == null) { head = node; size++; return; }
        Node cur = head;
        while (cur.next != null) cur = cur.next;
        cur.next = node;
        size++;
    }

    // 값으로 삭제 O(n)
    public boolean remove(int data) {
        if (head == null) return false;
        if (head.data == data) { head = head.next; size--; return true; }
        Node cur = head;
        while (cur.next != null && cur.next.data != data) cur = cur.next;
        if (cur.next == null) return false;
        cur.next = cur.next.next;   // 건너뛰기 → 삭제된 노드는 GC가 회수
        size--;
        return true;
    }
}
```

## 6. 자주 나오는 문제 유형

| 문제 | 핵심 아이디어 |
|---|---|
| 연결리스트 뒤집기 | prev, cur, next 세 포인터로 방향을 하나씩 바꿈 |
| 사이클 검출 | **플로이드 토끼와 거북이**: slow는 1칸, fast는 2칸. 만나면 사이클 존재 |
| 중간 노드 찾기 | fast가 끝에 도달할 때 slow가 중간 |
| 두 정렬 리스트 병합 | 더미 노드 + 작은 쪽부터 연결 |

```java
// 연결리스트 뒤집기
Node reverse(Node head) {
    Node prev = null, cur = head;
    while (cur != null) {
        Node next = cur.next; // 다음 노드 기억
        cur.next = prev;      // 방향 뒤집기
        prev = cur;
        cur = next;
    }
    return prev;
}
```

## 7. 면접 질문

1. **ArrayList와 LinkedList의 차이는?**
   → ArrayList는 배열 기반이라 조회 O(1), 중간 삽입·삭제 O(n). LinkedList는 노드 기반이라 조회 O(n), 위치를 알면 삽입·삭제 O(1). 실제로는 캐시 지역성 때문에 대부분 ArrayList가 빠릅니다.
2. **연결리스트에서 사이클을 어떻게 찾나요?**
   → 두 포인터의 속도를 다르게 이동시키는 플로이드 알고리즘으로 O(n) 시간, O(1) 공간에 찾습니다.
3. **이중 연결리스트를 쓰는 예는?**
   → LRU 캐시(HashMap + 이중 연결리스트), 브라우저 앞/뒤로 가기, Java `LinkedHashMap` 내부 구조.

---

## 핵심 정리
- 연결리스트 = **노드 + 포인터**, 메모리 비연속
- 조회 O(n), 위치를 알 때 삽입·삭제 O(1)
- 이중 연결리스트는 양방향 이동 + O(1) 삭제, 대신 메모리 추가
