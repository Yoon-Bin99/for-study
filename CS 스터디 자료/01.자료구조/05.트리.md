# 05. 트리 (Tree)

> **학습 목표**
> - 트리 용어(루트, 리프, 높이, 깊이 등)를 정확히 사용할 수 있다.
> - 이진 트리의 순회 4가지(전위·중위·후위·레벨)를 할 수 있다.
> - 이진 탐색 트리(BST)와 균형 트리(AVL, 레드블랙)의 필요성을 설명할 수 있다.

---

## 1. 개념과 용어

트리는 **사이클이 없는 연결 그래프**로, 계층 구조를 표현합니다. (파일 시스템, 조직도, HTML DOM)

```
              A          ← 루트 (깊이 0)
            /   \
           B     C       ← 깊이 1
          / \     \
         D   E     F     ← 리프 (깊이 2)
```

| 용어 | 뜻 | 예시 |
|---|---|---|
| 루트 (Root) | 부모가 없는 최상위 노드 | A |
| 리프 (Leaf) | 자식이 없는 노드 | D, E, F |
| 간선 (Edge) | 노드를 잇는 선 | 노드가 N개면 간선은 **N-1개** |
| 깊이 (Depth) | 루트에서 해당 노드까지 간선 수 | E의 깊이 = 2 |
| 높이 (Height) | 노드에서 가장 깊은 리프까지 간선 수 | 트리 높이 = 2 |
| 차수 (Degree) | 자식 노드 수 | B의 차수 = 2 |
| 서브트리 | 한 노드와 그 자손으로 이루어진 트리 | B, D, E |

---

## 2. 이진 트리 (Binary Tree)

모든 노드의 자식이 **최대 2개**인 트리입니다.

| 종류 | 정의 |
|---|---|
| 정 이진 트리 (Full) | 모든 노드의 자식이 0개 또는 2개 |
| 완전 이진 트리 (Complete) | 마지막 레벨을 제외하고 꽉 차 있고, 마지막 레벨은 **왼쪽부터** 채워짐 → **힙**의 구조 |
| 포화 이진 트리 (Perfect) | 모든 레벨이 꽉 참. 높이 h이면 노드 수 = 2^(h+1) - 1 |
| 편향 트리 (Skewed) | 한쪽으로만 자식이 이어짐 → 사실상 연결리스트 |

### 배열로 표현 (완전 이진 트리)
인덱스 1부터 시작할 때:
- 부모: `i / 2`
- 왼쪽 자식: `2i`
- 오른쪽 자식: `2i + 1`

## 3. 트리 순회 (Traversal)

```
        1
       / \
      2   3
     / \
    4   5
```

| 순회 | 순서 | 결과 | 용도 |
|---|---|---|---|
| 전위 (Preorder) | **루트** → 왼 → 오 | 1 2 4 5 3 | 트리 복사, 구조 출력 |
| 중위 (Inorder) | 왼 → **루트** → 오 | 4 2 5 1 3 | BST에서 **정렬된 순서** |
| 후위 (Postorder) | 왼 → 오 → **루트** | 4 5 2 3 1 | 트리 삭제, 디렉토리 용량 계산 |
| 레벨 (Level-order) | 위에서 아래, 왼에서 오 | 1 2 3 4 5 | BFS, 큐 사용 |

```java
class Node {
    int val; Node left, right;
    Node(int v) { val = v; }
}

void preorder(Node n)  { if (n == null) return; System.out.print(n.val + " "); preorder(n.left); preorder(n.right); }
void inorder(Node n)   { if (n == null) return; inorder(n.left); System.out.print(n.val + " "); inorder(n.right); }
void postorder(Node n) { if (n == null) return; postorder(n.left); postorder(n.right); System.out.print(n.val + " "); }

void levelOrder(Node root) {
    Queue<Node> q = new ArrayDeque<>();
    q.offer(root);
    while (!q.isEmpty()) {
        Node n = q.poll();
        System.out.print(n.val + " ");
        if (n.left != null) q.offer(n.left);
        if (n.right != null) q.offer(n.right);
    }
}
```

## 4. 이진 탐색 트리 (BST, Binary Search Tree)

**왼쪽 서브트리 < 노드 < 오른쪽 서브트리** 규칙을 만족하는 이진 트리입니다.

```
         8
       /   \
      3     10
     / \      \
    1   6      14
       / \
      4   7
```

- 탐색: 찾는 값이 현재보다 작으면 왼쪽, 크면 오른쪽 → 한 번 비교할 때마다 절반씩 줄어듦
- **중위 순회하면 정렬된 결과** (1 3 4 6 7 8 10 14)

### 연산
```java
Node search(Node n, int key) {
    if (n == null || n.val == key) return n;
    return key < n.val ? search(n.left, key) : search(n.right, key);
}

Node insert(Node n, int key) {
    if (n == null) return new Node(key);
    if (key < n.val) n.left = insert(n.left, key);
    else if (key > n.val) n.right = insert(n.right, key);
    return n;
}
```

### 삭제 3가지 경우
1. **리프 노드**: 그냥 삭제
2. **자식 1개**: 자식을 그 자리로 올림
3. **자식 2개**: 오른쪽 서브트리의 **최솟값(중위 후속자)** 또는 왼쪽 서브트리의 최댓값으로 값을 대체한 뒤, 그 노드를 삭제

### 시간복잡도
| 연산 | 평균 (균형) | 최악 (편향) |
|---|---|---|
| 탐색/삽입/삭제 | O(log n) | **O(n)** |

```
1, 2, 3, 4, 5 순서로 삽입하면?

1
 \
  2
   \
    3       ← 연결리스트와 다를 바 없음 → O(n)
     \
      4
```

→ 이 문제를 해결하기 위해 **균형 이진 탐색 트리**가 필요합니다.

## 5. 균형 이진 탐색 트리

삽입·삭제 시 **회전(rotation)** 으로 높이를 O(log n)으로 유지합니다.

### AVL 트리
- 모든 노드에서 **왼쪽과 오른쪽 서브트리 높이 차(균형 인수)가 1 이하**
- 엄격하게 균형을 맞춰 **조회가 빠름**
- 삽입·삭제 시 회전이 잦음
- 회전 유형: LL, RR, LR, RL

```
LL 불균형 → 오른쪽 회전

      30                20
     /                 /  \
    20       →        10   30
   /
  10
```

### 레드-블랙 트리
규칙:
1. 모든 노드는 빨강 또는 검정
2. 루트는 검정
3. 모든 리프(NIL)는 검정
4. 빨강 노드의 자식은 모두 검정 (빨강이 연속 X)
5. 어떤 노드에서 리프까지 가는 모든 경로의 **검정 노드 수가 같음**

- 결과적으로 가장 긴 경로가 가장 짧은 경로의 **2배를 넘지 않음** → 높이 O(log n)
- AVL보다 덜 엄격해서 **삽입·삭제 시 회전이 적음**
- **Java TreeMap, TreeSet, HashMap 버킷 트리화, C++ std::map** 에 사용

| 비교 | AVL | 레드블랙 |
|---|---|---|
| 균형 조건 | 엄격 (높이 차 ≤ 1) | 느슨함 |
| 조회 | 더 빠름 | 약간 느림 |
| 삽입·삭제 | 회전 많음 | 회전 적음 |
| 사용처 | 조회 위주 | 범용 (언어 라이브러리) |

## 6. B-Tree / B+Tree (간단히)

- 한 노드에 **여러 개의 키와 자식**을 가지는 균형 트리
- 높이가 매우 낮아 **디스크 I/O 횟수를 줄이기** 좋음
- **데이터베이스 인덱스**의 핵심 → `04.데이터베이스/04.인덱스.md`에서 자세히 다룹니다.

## 7. 면접 질문

1. **BST의 최악 시간복잡도와 해결법은?**
   → 정렬된 데이터를 넣으면 편향 트리가 되어 O(n). AVL·레드블랙 트리 같은 균형 트리로 O(log n)을 보장합니다.
2. **AVL과 레드블랙 트리의 차이는?**
   → AVL은 엄격한 균형으로 조회가 빠르고, 레드블랙은 느슨한 균형으로 삽입·삭제가 빠릅니다.
3. **트리와 그래프의 차이는?**
   → 트리는 사이클이 없고 모든 노드가 연결된 그래프이며, 노드 N개에 간선 N-1개입니다.
4. **BST에서 정렬된 결과를 얻으려면?**
   → 중위 순회를 합니다.

## 핵심 정리
- 트리 = 사이클 없는 연결 그래프, 간선 = N-1
- 순회: 전위(루트 먼저), 중위(BST 정렬), 후위(루트 마지막), 레벨(BFS)
- BST는 평균 O(log n), 최악 O(n) → 균형 트리(AVL, 레드블랙)로 보장
