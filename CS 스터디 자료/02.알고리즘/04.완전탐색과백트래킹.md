# 04. 완전 탐색과 백트래킹 (Brute Force & Backtracking)

> **학습 목표**
> - 완전 탐색이 가능한 입력 크기를 판단할 수 있다.
> - 순열·조합·부분집합을 재귀로 생성할 수 있다.
> - 백트래킹의 가지치기(pruning)를 설명할 수 있다.

---

## 1. 완전 탐색 (Brute Force)

**가능한 모든 경우를 전부 확인**하는 방법입니다. 가장 단순하지만 정답을 확실히 찾습니다.

- 먼저 **경우의 수를 계산**해서 시간 안에 가능한지 확인합니다.
- 1초 ≈ 1억 연산 기준

| 경우 | 경우의 수 | 가능한 n |
|---|---|---|
| 순열 (n개 나열) | n! | n ≤ 10 (10! ≈ 363만) |
| 부분집합 | 2ⁿ | n ≤ 20 (2²⁰ ≈ 100만) |
| 조합 nCr | n! / (r!(n-r)!) | n, r에 따라 |

> 코딩테스트에서 입력이 작으면(n ≤ 10~20) 완전 탐색을 먼저 의심하세요.

---

## 2. 순열 / 조합 / 부분집합

### 순열 (Permutation): 순서가 중요, nPr
```java
// n개 중 r개를 순서 있게 뽑기
int n = 3, r = 2;
int[] arr = {1, 2, 3};
boolean[] used = new boolean[n];
int[] picked = new int[r];

void permutation(int depth) {
    if (depth == r) {
        System.out.println(Arrays.toString(picked));
        return;
    }
    for (int i = 0; i < n; i++) {
        if (used[i]) continue;
        used[i] = true;
        picked[depth] = arr[i];
        permutation(depth + 1);
        used[i] = false;          // 원상 복구 (백트래킹)
    }
}
// [1,2] [1,3] [2,1] [2,3] [3,1] [3,2]
```

### 조합 (Combination): 순서 무관, nCr
```java
// start 이후만 고르면 중복 조합이 생기지 않음
void combination(int start, int depth) {
    if (depth == r) {
        System.out.println(Arrays.toString(picked));
        return;
    }
    for (int i = start; i < n; i++) {
        picked[depth] = arr[i];
        combination(i + 1, depth + 1);
    }
}
// [1,2] [1,3] [2,3]
```

### 부분집합 (Subset): 2ⁿ
```java
// 방법 1: 재귀 (각 원소를 넣는다 / 안 넣는다)
void subset(int idx, List<Integer> cur) {
    if (idx == n) { System.out.println(cur); return; }
    cur.add(arr[idx]);
    subset(idx + 1, cur);          // 넣는 경우
    cur.remove(cur.size() - 1);
    subset(idx + 1, cur);          // 안 넣는 경우
}

// 방법 2: 비트마스크
for (int mask = 0; mask < (1 << n); mask++) {
    List<Integer> s = new ArrayList<>();
    for (int i = 0; i < n; i++)
        if ((mask & (1 << i)) != 0) s.add(arr[i]);
    System.out.println(s);
}
```

### 비트마스크 기본 연산
| 연산 | 코드 |
|---|---|
| i번째 원소 포함 여부 | `(mask & (1 << i)) != 0` |
| i번째 원소 추가 | `mask \| (1 << i)` |
| i번째 원소 제거 | `mask & ~(1 << i)` |
| 원소 개수 | `Integer.bitCount(mask)` |

## 3. 백트래킹 (Backtracking)

완전 탐색을 하되, **더 진행해도 답이 될 수 없는 경로는 미리 포기하고 되돌아가는** 기법입니다. 이를 **가지치기(Pruning)** 라고 합니다.

```
             (시작)
          /    |    \
        A      B     C
       / \    ✗      / \
      ..  ..  (조건 위배 → 이 아래는 탐색 안 함)
```

- DFS로 상태 공간 트리를 탐색하면서
- **유망하지 않으면(promising X)** 즉시 돌아갑니다.
- 최악의 경우는 완전 탐색과 같지만 실제로는 훨씬 빠릅니다.

### 백트래킹 템플릿
```java
void backtrack(상태) {
    if (목표 도달) { 답 기록; return; }
    for (선택 가능한 후보) {
        if (!유망함(후보)) continue;   // 가지치기
        선택(후보);
        backtrack(다음 상태);
        선택 취소(후보);              // 원상 복구
    }
}
```

### 예시: N-Queen
N×N 체스판에 퀸 N개를 서로 공격하지 못하게 놓는 경우의 수

- 한 행에 퀸은 하나 → 행마다 열을 하나씩 고름
- 같은 열, 같은 대각선에 이미 퀸이 있으면 가지치기

```java
int n, count = 0;
boolean[] col, diag1, diag2;   // 열, ↘ 대각선(r+c), ↙ 대각선(r-c+n-1)

void solve(int row) {
    if (row == n) { count++; return; }
    for (int c = 0; c < n; c++) {
        if (col[c] || diag1[row + c] || diag2[row - c + n - 1]) continue; // 가지치기
        col[c] = diag1[row + c] = diag2[row - c + n - 1] = true;
        solve(row + 1);
        col[c] = diag1[row + c] = diag2[row - c + n - 1] = false;
    }
}
// 초기화: col = new boolean[n]; diag1 = new boolean[2*n-1]; diag2 = new boolean[2*n-1];
```

### 다른 가지치기 예시
- **합이 목표를 넘으면 중단** (부분집합의 합, 양수만 있을 때)
- **현재까지 비용이 지금까지의 최적해보다 크면 중단** (Branch and Bound)
- 스도쿠: 행·열·3×3 칸에 같은 숫자가 있으면 중단

## 4. 완전 탐색 vs 백트래킹 vs DFS

| 구분 | 설명 |
|---|---|
| 완전 탐색 | 모든 경우를 다 봄 (방법은 반복문, 재귀, 비트마스크 등) |
| DFS | 그래프/트리를 깊이 우선으로 탐색하는 **방법** |
| 백트래킹 | DFS로 탐색하면서 **가지치기**를 하는 기법 |

---

## 5. 면접 질문

1. **백트래킹과 완전 탐색의 차이는?**
   → 완전 탐색은 모든 경우를 확인하고, 백트래킹은 조건에 맞지 않는 경로를 미리 잘라내 탐색량을 줄입니다.
2. **순열과 조합 구현의 차이는?**
   → 순열은 방문 배열로 이미 쓴 원소만 제외하고 처음부터 다시 보며, 조합은 시작 인덱스를 넘겨 이전 원소를 다시 보지 않습니다.
3. **N-Queen 시간복잡도는?**
   → 최악 O(N!)이지만 가지치기로 실제 탐색량은 훨씬 적습니다.

---

## 핵심 정리
- 완전 탐색은 경우의 수 계산이 먼저 (n! → n≤10, 2ⁿ → n≤20)
- 순열: used 배열 / 조합: start 인덱스 / 부분집합: 넣기·안넣기 or 비트마스크
- 백트래킹 = DFS + 가지치기 + 원상 복구
