# 05. BFS와 DFS (그래프 탐색)

> **학습 목표**
> - BFS와 DFS의 탐색 순서 차이를 그림으로 설명할 수 있다.
> - 각각 큐/스택(재귀)으로 구현할 수 있다.
> - 문제 유형에 따라 BFS와 DFS 중 무엇을 쓸지 판단할 수 있다.

---

## 1. 탐색 순서 비교

```
        1
      /   \
     2     3
    / \     \
   4   5     6
```

| 탐색 | 순서 | 방식 |
|---|---|---|
| **DFS** (깊이 우선) | 1 → 2 → 4 → 5 → 3 → 6 | 한 방향으로 **끝까지 들어갔다가** 막히면 되돌아옴 |
| **BFS** (너비 우선) | 1 → 2 → 3 → 4 → 5 → 6 | 가까운 정점부터 **한 층씩** 넓혀감 |

비유: DFS는 미로에서 한 길을 끝까지 가보는 것, BFS는 물에 돌을 던졌을 때 퍼지는 물결

---

## 2. DFS (Depth-First Search)

- **스택** 또는 **재귀**로 구현
- 방문 체크를 하지 않으면 사이클에서 무한 루프

```java
List<List<Integer>> graph;
boolean[] visited;

// 재귀
void dfs(int v) {
    visited[v] = true;
    System.out.print(v + " ");
    for (int next : graph.get(v)) {
        if (!visited[next]) dfs(next);
    }
}

// 스택 (재귀 깊이가 깊어 StackOverflow가 우려될 때)
void dfsStack(int start) {
    Deque<Integer> stack = new ArrayDeque<>();
    stack.push(start);
    while (!stack.isEmpty()) {
        int v = stack.pop();
        if (visited[v]) continue;
        visited[v] = true;
        System.out.print(v + " ");
        // 작은 번호부터 방문하려면 역순으로 push
        List<Integer> adj = graph.get(v);
        for (int i = adj.size() - 1; i >= 0; i--) {
            if (!visited[adj.get(i)]) stack.push(adj.get(i));
        }
    }
}
```

### DFS가 유리한 문제
- **모든 경로**를 봐야 하는 문제 (경로의 특징 저장)
- **백트래킹** (순열, 조합, N-Queen)
- 사이클 판별, 연결 요소 개수
- 위상 정렬, 강한 연결 요소(SCC)
- 트리에서 서브트리 정보 계산

## 3. BFS (Breadth-First Search)

- **큐**로 구현
- **큐에 넣을 때 방문 처리**해야 같은 정점이 여러 번 들어가지 않습니다.

```java
void bfs(int start) {
    Queue<Integer> q = new ArrayDeque<>();
    q.offer(start);
    visited[start] = true;          // 넣을 때 방문 처리!
    while (!q.isEmpty()) {
        int v = q.poll();
        System.out.print(v + " ");
        for (int next : graph.get(v)) {
            if (!visited[next]) {
                visited[next] = true;
                q.offer(next);
            }
        }
    }
}
```

### BFS의 핵심 성질: 최단 거리
BFS는 시작점에서 가까운 순서대로 방문하므로, **가중치가 없는(모두 1인) 그래프에서 처음 도착한 거리가 최단 거리**입니다.

### 격자 최단 거리 (미로 탈출)
```java
int[] dr = {-1, 1, 0, 0}, dc = {0, 0, -1, 1};

int shortestPath(int[][] map, int R, int C) {
    int[][] dist = new int[R][C];
    for (int[] row : dist) Arrays.fill(row, -1);
    Queue<int[]> q = new ArrayDeque<>();
    q.offer(new int[]{0, 0});
    dist[0][0] = 0;

    while (!q.isEmpty()) {
        int[] cur = q.poll();
        int r = cur[0], c = cur[1];
        if (r == R - 1 && c == C - 1) return dist[r][c];
        for (int d = 0; d < 4; d++) {
            int nr = r + dr[d], nc = c + dc[d];
            if (nr < 0 || nr >= R || nc < 0 || nc >= C) continue;
            if (map[nr][nc] == 0 || dist[nr][nc] != -1) continue; // 벽 or 방문
            dist[nr][nc] = dist[r][c] + 1;
            q.offer(new int[]{nr, nc});
        }
    }
    return -1;  // 도달 불가
}
```

### BFS가 유리한 문제
- **가중치 없는 최단 거리** (미로, 최소 이동 횟수)
- 레벨(층) 단위 처리 (트리 레벨 순회, "k번 만에 갈 수 있는 곳")
- **멀티소스 BFS**: 여러 시작점을 처음부터 큐에 다 넣음 (토마토, 불 번지기)

## 4. 비교

| 항목 | DFS | BFS |
|---|---|---|
| 자료구조 | 스택 / 재귀 | 큐 |
| 탐색 방식 | 깊게 | 넓게 (가까운 순) |
| 최단 거리 | 보장 X | **가중치 없을 때 보장** |
| 메모리 | 경로 깊이만큼 | 한 레벨의 정점 수만큼 (넓은 그래프에서 큼) |
| 시간 (인접 리스트) | O(V + E) | O(V + E) |
| 시간 (인접 행렬) | O(V²) | O(V²) |
| 대표 문제 | 경로 탐색, 백트래킹, 사이클 | 최단 거리, 최소 횟수 |

> **둘 다 가능한 문제** (연결 요소 개수, 섬의 개수 등)는 편한 것을 쓰면 됩니다. 단, Java에서 재귀 DFS는 깊이가 1만~수만을 넘으면 StackOverflowError 위험이 있으니 BFS나 스택 DFS를 고려하세요.

## 5. 응용

### 연결 요소 개수 (섬의 개수)
```java
int count = 0;
for (int i = 0; i < n; i++) {
    if (!visited[i]) {
        dfs(i);       // 또는 bfs(i)
        count++;      // 새로 시작할 때마다 하나의 그룹
    }
}
```

### 0-1 BFS
가중치가 0 또는 1뿐일 때, 덱을 써서 **0이면 앞에, 1이면 뒤에** 넣습니다. 다익스트라보다 빠른 O(V + E).

## 6. 면접 질문

1. **BFS로 최단 거리를 구할 수 있는 이유는?**
   → 시작점에서 거리 1, 2, 3 ... 순서로 방문하므로 처음 방문했을 때의 거리가 최단입니다. 단, 가중치가 모두 같을 때만 성립합니다.
2. **BFS에서 큐에서 꺼낼 때 방문 처리하면 어떤 문제가?**
   → 같은 정점이 큐에 여러 번 들어가 메모리와 시간이 낭비됩니다.
3. **DFS와 BFS의 시간복잡도는?**
   → 인접 리스트 기준 둘 다 O(V + E)입니다.

---

## 핵심 정리
- DFS: 스택/재귀, 깊게 → 경로·백트래킹·사이클
- BFS: 큐, 넓게 → **가중치 없는 최단 거리**
- BFS는 **넣을 때 방문 처리**, 시간은 둘 다 O(V + E)
