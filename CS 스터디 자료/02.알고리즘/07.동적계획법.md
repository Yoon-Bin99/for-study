# 07. 동적 계획법 (Dynamic Programming, DP)

> **학습 목표**
> - DP가 적용되는 두 조건(중복 부분 문제, 최적 부분 구조)을 설명할 수 있다.
> - Top-down(메모이제이션)과 Bottom-up(타뷸레이션)을 구현할 수 있다.
> - 대표 DP 문제의 점화식을 세울 수 있다.

---

## 1. 개념

DP는 **큰 문제를 작은 부분 문제로 나누고, 부분 문제의 답을 저장해 두었다가 재사용**하는 방법입니다.

### 왜 필요한가? — 피보나치
```
fib(5)
├── fib(4)
│   ├── fib(3)
│   │   ├── fib(2)  ← 중복
│   │   └── fib(1)
│   └── fib(2)      ← 중복
└── fib(3)          ← 중복 (위에서 이미 계산함)
    ├── fib(2)
    └── fib(1)
```
단순 재귀는 같은 값을 반복 계산해서 **O(2ⁿ)** 입니다. 한 번 계산한 값을 저장하면 **O(n)** 이 됩니다.

---

## 2. DP 적용 조건

1. **중복되는 부분 문제 (Overlapping Subproblems)**
   같은 부분 문제가 여러 번 등장한다.
2. **최적 부분 구조 (Optimal Substructure)**
   큰 문제의 최적해를 부분 문제의 최적해로 만들 수 있다.

> **분할 정복과 차이**: 병합 정렬도 문제를 나누지만, 나눈 부분 문제가 **겹치지 않아서** 저장할 필요가 없습니다. DP는 부분 문제가 **겹칩니다.**

---

## 3. 구현 방식 2가지

### Top-down (메모이제이션, 재귀)
큰 문제에서 시작해 필요한 부분 문제를 재귀로 호출하고, 결과를 저장합니다.

```java
long[] memo = new long[100];

long fib(int n) {
    if (n <= 1) return n;
    if (memo[n] != 0) return memo[n];     // 이미 계산했으면 재사용
    return memo[n] = fib(n - 1) + fib(n - 2);
}
```

### Bottom-up (타뷸레이션, 반복문)
가장 작은 문제부터 차례로 표(dp 배열)를 채웁니다.

```java
long fib(int n) {
    if (n <= 1) return n;
    long[] dp = new long[n + 1];
    dp[0] = 0; dp[1] = 1;
    for (int i = 2; i <= n; i++) dp[i] = dp[i - 1] + dp[i - 2];
    return dp[n];
}
```

| 비교 | Top-down | Bottom-up |
|---|---|---|
| 구현 | 점화식을 그대로 재귀로 → 직관적 | 계산 순서를 직접 정해야 함 |
| 계산 범위 | **필요한 부분 문제만** 계산 | 모든 부분 문제 계산 |
| 성능 | 재귀 호출 오버헤드, StackOverflow 위험 | 보통 더 빠름 |
| 공간 최적화 | 어려움 | 쉬움 (이전 행만 유지 등) |

---

## 4. DP 문제 푸는 순서

1. **상태 정의**: `dp[i]`가 무엇을 의미하는지 한 문장으로 정한다.
2. **점화식**: `dp[i]`를 더 작은 상태로 표현한다.
3. **초기값**: 가장 작은 상태의 값을 정한다.
4. **계산 순서**: 작은 것 → 큰 것
5. **답의 위치**: `dp[n]`인지, `max(dp[...])`인지

---

## 5. 대표 문제

### 5-1. 계단 오르기 (1칸 또는 2칸)
- 상태: `dp[i]` = i번째 계단에 오르는 방법의 수
- 점화식: `dp[i] = dp[i-1] + dp[i-2]` (직전에 1칸 왔거나 2칸 왔거나)

### 5-2. 최장 증가 부분 수열 (LIS)
> [10, 20, 10, 30, 20, 50] → 가장 긴 증가 부분 수열 [10, 20, 30, 50], 길이 4

- 상태: `dp[i]` = i번째 원소로 **끝나는** LIS 길이
- 점화식: `dp[i] = max(dp[j] + 1)` (j < i 이고 a[j] < a[i])

```java
int lis(int[] a) {
    int n = a.length, ans = 0;
    int[] dp = new int[n];
    for (int i = 0; i < n; i++) {
        dp[i] = 1;
        for (int j = 0; j < i; j++)
            if (a[j] < a[i]) dp[i] = Math.max(dp[i], dp[j] + 1);
        ans = Math.max(ans, dp[i]);
    }
    return ans;   // O(n²)
}
```
> 이분 탐색을 쓰면 O(n log n)으로 개선할 수 있습니다.

### 5-3. 0/1 배낭 문제 (Knapsack)
> 무게 제한 W인 가방에 물건(무게 w, 가치 v)을 넣어 가치 합을 최대로. 물건은 쪼갤 수 없다.

- 상태: `dp[i][j]` = i번째 물건까지 고려했고 무게 한도가 j일 때 최대 가치
- 점화식:
  - i번째 물건을 안 넣음: `dp[i-1][j]`
  - 넣음 (j ≥ w[i]): `dp[i-1][j - w[i]] + v[i]`
  - `dp[i][j] = max(위 두 값)`

```java
int knapsack(int[] w, int[] v, int W) {
    int n = w.length;
    int[] dp = new int[W + 1];          // 1차원으로 공간 최적화
    for (int i = 0; i < n; i++) {
        for (int j = W; j >= w[i]; j--) {   // 뒤에서부터! (같은 물건 중복 사용 방지)
            dp[j] = Math.max(dp[j], dp[j - w[i]] + v[i]);
        }
    }
    return dp[W];   // O(n × W)
}
```

### 5-4. 최장 공통 부분 수열 (LCS)
> "ACAYKP", "CAPCAK" → LCS "ACAK", 길이 4

- 상태: `dp[i][j]` = A의 앞 i글자, B의 앞 j글자의 LCS 길이
- 점화식:
  - `A[i] == B[j]`: `dp[i][j] = dp[i-1][j-1] + 1`
  - 다르면: `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`

```java
int lcs(String a, String b) {
    int n = a.length(), m = b.length();
    int[][] dp = new int[n + 1][m + 1];
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            dp[i][j] = a.charAt(i - 1) == b.charAt(j - 1)
                     ? dp[i - 1][j - 1] + 1
                     : Math.max(dp[i - 1][j], dp[i][j - 1]);
    return dp[n][m];
}
```

### 5-5. 격자 경로의 최솟값/경우의 수
- `dp[r][c] = map[r][c] + min(dp[r-1][c], dp[r][c-1])` (위 또는 왼쪽에서 옴)

## 6. 자주 쓰는 DP 유형 정리

| 유형 | 상태 | 예시 문제 |
|---|---|---|
| 1차원 | dp[i] | 계단, 피보나치, 1로 만들기, 최대 부분합 |
| 2차원 | dp[i][j] | 배낭, LCS, 편집 거리, 격자 경로 |
| 구간 DP | dp[l][r] | 행렬 곱셈 순서, 팰린드롬 분할 |
| 비트마스크 DP | dp[mask][i] | 외판원 순회(TSP) |
| 트리 DP | dp[node][상태] | 트리의 독립 집합 |

## 7. 면접 질문

1. **DP와 분할 정복의 차이는?**
   → 둘 다 문제를 나누지만, DP는 부분 문제가 중복되어 결과를 저장·재사용하고, 분할 정복은 부분 문제가 독립적입니다.
2. **메모이제이션과 타뷸레이션의 차이는?**
   → 메모이제이션은 재귀로 필요한 것만 계산하며 저장하고, 타뷸레이션은 반복문으로 작은 문제부터 표를 채웁니다.
3. **0/1 배낭을 1차원 배열로 풀 때 j를 거꾸로 도는 이유는?**
   → 앞에서부터 돌면 이번 물건으로 갱신된 값을 같은 반복에서 다시 써서 같은 물건을 여러 번 넣게 되기 때문입니다.

---

## 핵심 정리
- DP = 부분 문제 결과 저장 후 재사용 (중복 부분 문제 + 최적 부분 구조)
- Top-down(재귀+메모) / Bottom-up(반복문+표)
- 풀이 순서: 상태 정의 → 점화식 → 초기값 → 계산 순서 → 답 위치
