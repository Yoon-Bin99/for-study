# 08. 최단 경로 (Shortest Path)

> **학습 목표**
> - 다익스트라, 벨만-포드, 플로이드-워셜의 차이와 사용 조건을 설명할 수 있다.
> - 우선순위 큐를 이용한 다익스트라를 구현할 수 있다.
> - 음수 간선과 음수 사이클의 의미를 이해한다.

---

## 1. 어떤 알고리즘을 쓸까?

| 상황 | 알고리즘 | 시간복잡도 |
|---|---|---|
| 가중치가 없음 (모두 1) | **BFS** | O(V + E) |
| 한 정점 → 모든 정점, **음수 간선 없음** | **다익스트라** | O(E log V) |
| 한 정점 → 모든 정점, **음수 간선 있음** | **벨만-포드** | O(V × E) |
| **모든 정점 → 모든 정점** | **플로이드-워셜** | O(V³) |

---

## 2. 다익스트라 (Dijkstra)

### 아이디어
**아직 확정되지 않은 정점 중 거리가 가장 짧은 정점을 골라 확정하고, 그 정점을 거쳐 가는 경로로 이웃의 거리를 갱신**합니다. (그리디)

### 동작 예시
```
      (A)
    4/   \1
   (B)    (C)
    1\   /5  \8
      (D)     (E)
  간선: A-B 4, A-C 1, B-D 1, C-D 5, C-E 8  (무방향으로 가정)

시작: A
초기   dist: A=0, B=∞, C=∞, D=∞, E=∞
A 확정 → B=4, C=1
C 확정(1) → D=min(∞, 1+5)=6, E=1+8=9
B 확정(4) → D=min(6, 4+1)=5
D 확정(5) → 갱신 없음
E 확정(9)
결과: A=0, B=4, C=1, D=5, E=9
```

### 음수 간선이 있으면 안 되는 이유
다익스트라는 "한 번 확정된 거리는 더 짧아지지 않는다"고 가정합니다. 음수 간선이 있으면 나중에 더 짧은 경로가 생길 수 있어 이 가정이 깨집니다.

### Java 구현 (우선순위 큐)
```java
int[] dijkstra(List<List<int[]>> graph, int start, int n) {
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[start] = 0;

    // {정점, 거리}, 거리 오름차순
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> Integer.compare(a[1], b[1]));
    pq.offer(new int[]{start, 0});

    while (!pq.isEmpty()) {
        int[] cur = pq.poll();
        int v = cur[0], d = cur[1];
        if (d > dist[v]) continue;          // 이미 더 짧은 거리로 처리됨 → 스킵

        for (int[] edge : graph.get(v)) {
            int next = edge[0], cost = edge[1];
            if (dist[v] + cost < dist[next]) {
                dist[next] = dist[v] + cost;
                pq.offer(new int[]{next, dist[next]});
            }
        }
    }
    return dist;
}
```

- `if (d > dist[v]) continue;` 를 빼먹으면 같은 정점을 여러 번 처리해 느려집니다.
- 거리 합이 int 범위를 넘을 수 있으면 `long`을 쓰세요.

## 3. 벨만-포드 (Bellman-Ford)

### 아이디어
**모든 간선을 V-1번 반복해서 완화(relaxation)** 합니다. 최단 경로는 최대 V-1개의 간선을 가지기 때문입니다.

```java
long[] bellmanFord(int n, int[][] edges, int start) {   // edges: {u, v, w}
    long INF = Long.MAX_VALUE;
    long[] dist = new long[n];
    Arrays.fill(dist, INF);
    dist[start] = 0;

    for (int i = 0; i < n - 1; i++) {
        for (int[] e : edges) {
            if (dist[e[0]] != INF && dist[e[0]] + e[2] < dist[e[1]])
                dist[e[1]] = dist[e[0]] + e[2];
        }
    }
    // V번째에도 갱신되면 음수 사이클 존재
    for (int[] e : edges) {
        if (dist[e[0]] != INF && dist[e[0]] + e[2] < dist[e[1]])
            return null;   // 음수 사이클
    }
    return dist;
}
```

### 음수 사이클
```
A --(1)--> B --(-3)--> C --(1)--> A     사이클 합 = -1
```
돌 때마다 거리가 줄어들어 최단 거리가 **-∞**가 됩니다. 벨만-포드는 이를 **검출**할 수 있습니다.

## 4. 플로이드-워셜 (Floyd-Warshall)

### 아이디어
**모든 정점 쌍(i, j)에 대해 "k를 거쳐 가는 게 더 짧은가?"** 를 모든 k에 대해 확인합니다. (DP)

`dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])`

```java
void floyd(int[][] dist, int n) {   // dist[i][i] = 0, 연결 안 됨 = INF
    for (int k = 0; k < n; k++)              // 거쳐 가는 정점 k가 가장 바깥!
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                if (dist[i][k] + dist[k][j] < dist[i][j])
                    dist[i][j] = dist[i][k] + dist[k][j];
}
```

- **k가 반드시 가장 바깥 루프**여야 합니다.
- INF를 `Integer.MAX_VALUE`로 두면 더할 때 오버플로 → `1e9` 같은 값을 씁니다.
- V ≤ 500 정도에서 사용 (500³ = 1.25억)

## 5. 비교 정리

| 항목 | 다익스트라 | 벨만-포드 | 플로이드-워셜 |
|---|---|---|---|
| 문제 | 단일 출발 | 단일 출발 | 모든 쌍 |
| 음수 간선 | **X** | O | O |
| 음수 사이클 검출 | X | **O** | O (`dist[i][i] < 0`) |
| 시간 | O(E log V) | O(VE) | O(V³) |
| 방식 | 그리디 + 우선순위 큐 | 모든 간선 V-1번 완화 | DP |

## 6. 실생활 예
- 내비게이션, 지도 길찾기: 다익스트라 변형(A* 알고리즘)
- 네트워크 라우팅: **OSPF**는 다익스트라(링크 상태), **RIP**는 벨만-포드(거리 벡터) 기반 (→ `05.네트워크/03.네트워크계층.md`)

## 7. 면접 질문

1. **다익스트라에서 음수 가중치를 쓸 수 없는 이유는?**
   → 확정된 정점의 거리가 이후 더 짧아질 수 없다는 그리디 가정이 깨지기 때문입니다.
2. **다익스트라의 시간복잡도는?**
   → 우선순위 큐 사용 시 O(E log V), 배열로 최솟값을 찾으면 O(V²)입니다.
3. **플로이드-워셜에서 k를 가장 바깥에 두는 이유는?**
   → "1~k번 정점만 거쳐 갈 때의 최단 거리"를 k를 늘려가며 계산하는 DP이기 때문에, k단계가 완전히 끝난 뒤 k+1단계로 넘어가야 합니다.

## 핵심 정리
- 가중치 없음 → BFS / 음수 없음 → 다익스트라 / 음수 있음 → 벨만-포드 / 모든 쌍 → 플로이드
- 다익스트라: PQ + `if (d > dist[v]) continue`
- 벨만-포드: V번째 갱신 = 음수 사이클
- 플로이드: k가 가장 바깥 루프, INF 오버플로 주의
