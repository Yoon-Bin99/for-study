# Part 1. 최소 신장 트리 (MST, Minimum Spanning Tree)

## 1. 개념

- **신장 트리 (Spanning Tree)**: 그래프의 **모든 정점을 포함**하면서 **사이클이 없는** 부분 그래프. 정점이 V개면 간선은 **V-1개**
- **최소 신장 트리**: 신장 트리 중 **간선 가중치 합이 최소**인 것

```
원래 그래프                    MST (합 = 1 + 2 + 3 = 6)
   A ──4── B                     A       B
   │ ╲     │                     │ ╲     │
   1   3   2                     1   3   2
   │     ╲ │                     │     ╲ │
   C ──5── D                     C       D
```

활용: 최소 비용으로 도시들을 도로/통신망으로 연결, 클러스터링

## 2. 크루스칼 (Kruskal) — 간선 중심

1. 모든 간선을 **가중치 오름차순으로 정렬**
2. 가장 가벼운 간선부터 보면서, **사이클이 생기지 않으면** 선택
3. V-1개를 선택하면 종료

사이클 판별은 **유니온 파인드**로 합니다. (→ `01.자료구조/08.트라이와유니온파인드.md`)

```java
int kruskal(int n, int[][] edges) {    // edges: {u, v, w}
    Arrays.sort(edges, (a, b) -> Integer.compare(a[2], b[2]));
    int[] parent = new int[n];
    for (int i = 0; i < n; i++) parent[i] = i;

    int total = 0, count = 0;
    for (int[] e : edges) {
        int ru = find(parent, e[0]), rv = find(parent, e[1]);
        if (ru == rv) continue;          // 같은 집합 → 사이클
        parent[ru] = rv;                 // union
        total += e[2];
        if (++count == n - 1) break;
    }
    return total;
}

int find(int[] p, int x) {
    return p[x] == x ? x : (p[x] = find(p, p[x]));
}
```
시간복잡도: **O(E log E)** (정렬이 지배적)

## 3. 프림 (Prim) — 정점 중심

1. 임의의 정점 하나에서 시작
2. **현재 트리에 연결된 간선 중 가장 가벼운 간선**으로 새 정점을 추가 (우선순위 큐)
3. 모든 정점이 포함될 때까지 반복

```java
int prim(List<List<int[]>> graph, int n) {   // graph: {next, w}
    boolean[] inTree = new boolean[n];
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> Integer.compare(a[1], b[1]));
    pq.offer(new int[]{0, 0});
    int total = 0, count = 0;

    while (!pq.isEmpty() && count < n) {
        int[] cur = pq.poll();
        if (inTree[cur[0]]) continue;
        inTree[cur[0]] = true;
        total += cur[1];
        count++;
        for (int[] e : graph.get(cur[0]))
            if (!inTree[e[0]]) pq.offer(new int[]{e[0], e[1]});
    }
    return total;
}
```
시간복잡도: **O(E log V)**

## 4. 크루스칼 vs 프림

| 항목 | 크루스칼 | 프림 |
|---|---|---|
| 기준 | 간선 | 정점 |
| 자료구조 | 정렬 + 유니온 파인드 | 우선순위 큐 |
| 시간 | O(E log E) | O(E log V) |
| 유리한 그래프 | **희소 그래프** (간선 적음) | **밀집 그래프** (간선 많음) |

> 프림은 다익스트라와 구조가 거의 같습니다. 차이는 PQ에 넣는 값이 **"시작점부터의 거리"(다익스트라)** 인지 **"간선 하나의 가중치"(프림)** 인지입니다.

# Part 2. 위상 정렬 (Topological Sort)

## 1. 개념

**방향 그래프에서 간선 방향을 거스르지 않도록 정점을 나열**하는 것입니다. "A를 해야 B를 할 수 있다"는 선후 관계가 있을 때 작업 순서를 정합니다.

- **DAG(사이클 없는 방향 그래프)** 에서만 가능합니다. 사이클이 있으면 순서를 정할 수 없습니다.
- 답이 여러 개일 수 있습니다.

```
선수 과목 관계
자료구조 → 알고리즘 → 인공지능
    ↓
 운영체제 → 시스템프로그래밍

가능한 순서: 자료구조, 알고리즘, 운영체제, 인공지능, 시스템프로그래밍
```

활용: 선수 과목, 빌드 순서(Gradle/Maven 의존성), 작업 스케줄링, 스프레드시트 셀 계산 순서

## 2. 칸 알고리즘 (Kahn's Algorithm, BFS 방식)

1. 모든 정점의 **진입 차수(in-degree)** 를 계산
2. 진입 차수가 **0인 정점을 큐에** 넣음
3. 큐에서 꺼내 결과에 추가하고, 그 정점에서 나가는 간선을 제거 (이웃의 진입 차수 -1)
4. 진입 차수가 0이 된 정점을 큐에 넣음
5. 큐가 빌 때까지 반복

```java
List<Integer> topologicalSort(List<List<Integer>> graph, int n) {
    int[] indegree = new int[n];
    for (int u = 0; u < n; u++)
        for (int v : graph.get(u)) indegree[v]++;

    Queue<Integer> q = new ArrayDeque<>();
    for (int i = 0; i < n; i++) if (indegree[i] == 0) q.offer(i);

    List<Integer> result = new ArrayList<>();
    while (!q.isEmpty()) {
        int u = q.poll();
        result.add(u);
        for (int v : graph.get(u)) {
            if (--indegree[v] == 0) q.offer(v);
        }
    }

    if (result.size() != n) return null;   // 사이클 존재
    return result;
}
```

- **결과 개수가 V보다 적으면 사이클이 있다**는 뜻입니다.
- 시간복잡도: **O(V + E)**

## 3. DFS 방식
DFS가 끝나는 순서(후위)대로 스택에 쌓은 뒤 **뒤집으면** 위상 정렬 결과가 됩니다.

## 면접 질문

1. **크루스칼과 프림의 차이는?**
   → 크루스칼은 간선을 정렬해 가벼운 것부터 사이클 없이 추가하고, 프림은 한 정점에서 시작해 연결된 가장 가벼운 간선으로 확장합니다. 희소 그래프는 크루스칼, 밀집 그래프는 프림이 유리합니다.
2. **위상 정렬이 가능한 조건과 사이클 판별 방법은?**
   → DAG여야 합니다. 칸 알고리즘에서 결과에 포함된 정점 수가 V보다 적으면 사이클이 있습니다.
3. **MST의 간선 수는?**
   → V-1개입니다.

## 핵심 정리
- MST = 모든 정점 연결 + 사이클 X + 가중치 합 최소, 간선 V-1개
- 크루스칼: 간선 정렬 + 유니온 파인드 / 프림: 우선순위 큐
- 위상 정렬: DAG에서만, 진입 차수 0부터 큐로 (O(V+E))
