# CS 스터디 자료

컴퓨터공학 학부 수준의 CS 핵심 개념을 대분류 → 소분류 구조로 정리한 학습 자료입니다.

## 문서 구성

각 문서는 같은 흐름으로 작성되어 있습니다.

1. **학습 목표**: 이 문서를 읽고 나서 할 수 있어야 하는 것
2. **개념과 동작 원리**: 그림(ASCII)과 표로 설명
3. **비교표 / 시간복잡도**
4. **Java 예시 코드**
5. **면접 질문**: 질문과 모범 답변 요지
6. **핵심 정리**: 3~5줄 요약
