# 02. 스트림 API

> **학습 목표**
> - 스트림의 구조(생성 → 중간 연산 → 최종 연산)와 지연 평가를 설명할 수 있다.
> - map, filter, flatMap, sorted, distinct 등 중간 연산을 활용할 수 있다.
> - collect(groupingBy, toMap, partitioningBy), reduce로 결과를 만들 수 있다.
> - 스트림의 주의점(재사용 불가, 부수 효과, 병렬 스트림)을 설명할 수 있다.

---

## 1. 스트림이란?

**컬렉션의 요소를 선언적으로 처리**하는 파이프라인입니다. "어떻게"가 아니라 "무엇을" 할지 씁니다.

```java
// 명령형
List<String> result = new ArrayList<>();
for (Member m : members) {
    if (m.getAge() >= 20) result.add(m.getName());
}
Collections.sort(result);

// 스트림
List<String> result = members.stream()
        .filter(m -> m.getAge() >= 20)
        .map(Member::getName)
        .sorted()
        .toList();
```

```
[생성]          [중간 연산 (0개 이상)]            [최종 연산 (1개)]
stream()  →  filter → map → sorted ...  →  toList / collect / count / forEach
              (Stream 반환, 지연)               (결과 반환, 이때 실행)
```

### 특징
| 특징 | 설명 |
|---|---|
| **원본을 바꾸지 않음** | 새 결과를 만듦 |
| **지연 평가 (Lazy)** | 최종 연산이 호출될 때 비로소 실행 |
| **한 번만 사용** | 최종 연산 후 재사용하면 `IllegalStateException` |
| 내부 반복 | 반복을 스트림이 처리 → 최적화·병렬화 여지 |

### 지연 평가와 쇼트서킷
```java
Stream.of("a", "bb", "ccc", "dddd")
      .filter(s -> { System.out.println("filter " + s); return s.length() > 1; })
      .map(s -> { System.out.println("map " + s); return s.toUpperCase(); })
      .findFirst();
// filter a → filter bb → map bb → 끝 (나머지는 처리하지 않음)
```
요소 하나씩 **파이프라인 전체를 통과**하고(수직 실행), `findFirst`, `anyMatch`, `limit`는 필요한 만큼만 처리합니다.

## 2. 스트림 생성

```java
list.stream();
```

## 3. 중간 연산

| 연산 | 설명 |
|---|---|
| `filter(Predicate)` | 조건에 맞는 것만 |
| `map(Function)` | 변환 |
| `mapToInt/Long/Double` | 기본형 스트림으로 (sum, average 가능) |
| **`flatMap(Function<T, Stream<R>>)`** | 각 요소를 스트림으로 바꾼 뒤 **평탄화** |
| `distinct()` | 중복 제거 (equals 기준) |
| `sorted()` / `sorted(Comparator)` | 정렬 |
| `limit(n)` / `skip(n)` | 앞 n개 / n개 건너뛰기 |
| `peek(Consumer)` | 중간 확인 (디버깅용) |
| `takeWhile` / `dropWhile` | 조건이 참인 동안 가져오기 / 버리기 (Java 9+) |
| `mapMulti` | flatMap 대안 (Java 16+) |

### flatMap
```java
List<List<String>> nested = List.of(List.of("a", "b"), List.of("c"));
nested.stream().flatMap(List::stream).toList();          // [a, b, c]

// 주문들의 모든 상품 이름
orders.stream()
      .flatMap(order -> order.getItems().stream())
      .map(OrderItem::getProductName)
      .distinct()
      .toList();
```

## 4. 최종 연산

| 연산 | 반환 |
|---|---|
| `toList()` (Java 16+) | 불변 List |
| `collect(Collector)` | 다양한 결과 |
| `forEach(Consumer)` | 없음 |
| `count()` | long |
| `anyMatch / allMatch / noneMatch` | boolean |
| `findFirst / findAny` | Optional |
| `min / max(Comparator)` | Optional |
| `reduce` | 누적 결과 |
| `sum / average` (기본형 스트림) | int·long·double / OptionalDouble |

### reduce
```java
int sum = numbers.stream().reduce(0, Integer::sum);
Optional<Integer> max = numbers.stream().reduce(Integer::max);
long total = orders.stream().mapToLong(Order::getAmount).sum();   // 합계는 이게 더 간단
```

## 5. Collectors

```java
import static java.util.stream.Collectors.*;

// 리스트·셋
List<String> names = members.stream().map(Member::getName).collect(toList());   // 수정 가능 리스트
Set<String> set = stream.collect(toSet());

// 문자열 연결
String csv = names.stream().collect(joining(", ", "[", "]"));   // [kim, lee]

// Map으로
Map<Long, Member> byId = members.stream().collect(toMap(Member::getId, m -> m));
// 키 중복 시 IllegalStateException → 병합 함수 지정
Map<String, Integer> nameToAge = members.stream()
        .collect(toMap(Member::getName, Member::getAge, (a, b) -> a));
// Function.identity() == m -> m

// 그룹핑
Map<Grade, List<Member>> byGrade = members.stream().collect(groupingBy(Member::getGrade));
Map<Grade, Long> countByGrade = members.stream().collect(groupingBy(Member::getGrade, counting()));
Map<Grade, Double> avgAge = members.stream().collect(groupingBy(Member::getGrade, averagingInt(Member::getAge)));
Map<Grade, List<String>> namesByGrade = members.stream()
        .collect(groupingBy(Member::getGrade, mapping(Member::getName, toList())));
Map<Grade, Optional<Member>> oldest = members.stream()
        .collect(groupingBy(Member::getGrade, maxBy(Comparator.comparingInt(Member::getAge))));

// 분할 (true / false 두 그룹)
Map<Boolean, List<Member>> adultOrNot = members.stream().collect(partitioningBy(m -> m.getAge() >= 20));

// 통계
IntSummaryStatistics stats = members.stream().mapToInt(Member::getAge).summaryStatistics();
stats.getAverage(); stats.getMax(); stats.getCount();
```

| 주의 | |
|---|---|
| `toMap` 키 중복 | 예외 → 병합 함수 지정 |
| `toMap` 값이 null | NPE |
| `groupingBy` 결과 순서 | HashMap → 정렬이 필요하면 `groupingBy(f, TreeMap::new, toList())` |
| `toList()` vs `collect(toList())` | 전자는 **불변**, 후자는 수정 가능 (명세상 보장은 X) |

## 6. 주의점

### 부수 효과 금지
```java
// ❌ 스트림 안에서 외부 상태 변경
List<String> result = new ArrayList<>();
members.stream().filter(...).forEach(m -> result.add(m.getName()));   // 병렬 시 깨짐, 의도 불명확

// ✅ 결과는 collect로
List<String> result = members.stream().filter(...).map(Member::getName).toList();
```

### 무조건 스트림이 좋은 것은 아니다
| 스트림이 좋은 경우 | for문이 나은 경우 |
|---|---|
| 필터·변환·집계 파이프라인 | **break/continue/return이 복잡**한 흐름 |
| 그룹핑·통계 | Checked 예외를 던져야 할 때 |
| 가독성이 좋아질 때 | 인덱스가 필요할 때, 성능이 아주 중요한 단순 반복 |

### 병렬 스트림 (parallelStream)
```java
long count = bigList.parallelStream().filter(...).count();
```
- 내부적으로 **공용 ForkJoinPool**(코어 수 - 1개 스레드)을 사용
- **웹 서버에서는 거의 쓰지 않습니다**: 공용 풀을 모든 요청이 공유해 서로 막고, I/O 작업(DB, API 호출)은 오히려 느려짐
- 적합: **CPU 연산이 무겁고, 데이터가 크고, 순서가 중요하지 않고, 분할이 쉬운(ArrayList, 배열)** 경우. 반드시 측정 후 사용

### 무한 스트림
`Stream.iterate`, `generate`는 `limit`나 쇼트서킷 연산 없이 쓰면 끝나지 않습니다.

## 7. 면접 질문

1. **스트림의 지연 평가란?**
   → 중간 연산은 호출해도 바로 실행되지 않고 최종 연산이 호출될 때 요소 단위로 파이프라인을 통과하며 실행되는 것으로, 필요한 만큼만 처리하는 쇼트서킷 최적화가 가능합니다.
2. **map과 flatMap의 차이는?**
   → map은 요소를 하나의 값으로 변환하고, flatMap은 요소를 스트림으로 변환한 뒤 하나의 스트림으로 평탄화합니다.
3. **병렬 스트림을 웹 애플리케이션에서 조심해야 하는 이유는?**
   → 공용 ForkJoinPool을 애플리케이션 전체가 공유해 요청끼리 자원을 경쟁하고, I/O 작업에서는 이점이 없으며, 순서·스레드 안전 문제가 생길 수 있기 때문입니다.
4. **toMap 사용 시 주의할 점은?**
   → 키가 중복되면 예외가 나므로 병합 함수를 지정해야 하고, 값이 null이면 NPE가 발생합니다.

---

## 핵심 정리
- 생성 → 중간 연산(지연) → 최종 연산(실행), 원본 불변, 재사용 불가
- 중간: `filter map flatMap distinct sorted limit`, 기본형 스트림으로 sum/average
- 최종: `toList collect count anyMatch findFirst reduce`
- Collectors: `toMap`(병합 함수), `groupingBy`(+counting, mapping), `partitioningBy`, `joining`
- 부수 효과 금지, 복잡한 흐름은 for문, 병렬 스트림은 측정 후 신중히
