# 04. 모던 자바 (Java 9 ~ 25 주요 기능)

> **학습 목표**
> - LTS 버전(8, 11, 17, 21, 25)의 의미와 주요 기능을 말할 수 있다.
> - var, switch 식, 텍스트 블록, record, sealed, 패턴 매칭을 사용할 수 있다.
> - Java 21·25의 핵심 변화(가상 스레드, Sequenced Collections, Scoped Values 등)를 설명할 수 있다.

---

## 1. 릴리스 주기와 LTS

- Java 9부터 **6개월마다** 새 버전 (3월, 9월)
- **LTS (Long-Term Support)**: 2년마다, 장기 지원 → 실무는 LTS를 씀

| LTS | 출시 | 핵심 |
|---|---|---|
| 8 | 2014 | 람다, 스트림, Optional, java.time |
| 11 | 2018 | var(10), HttpClient, String 메서드 |
| **17** | 2021 | record, sealed, 패턴 매칭 instanceof, switch 식, 텍스트 블록 — **Spring Boot 3·4의 최소 버전** |
| **21** | 2023 | **가상 스레드**, switch 패턴 매칭, record 패턴, Sequenced Collections |
| **25** | 2025 | Scoped Values, 유연한 생성자 본문, 간단한 main, Compact Object Headers |

## 2. Java 10~17

### var (10): 지역 변수 타입 추론
```java
var list = new ArrayList<Member>();         // ArrayList<Member>
var map = new HashMap<String, List<Order>>();
for (var entry : map.entrySet()) { ... }
```
- **지역 변수에만** (필드, 파라미터, 반환 타입 X), 초기값 필수
- 타입이 오른쪽에서 명확할 때만 사용 (`var x = service.process();`처럼 타입을 알기 어려우면 지양)

### switch 식 (14)
```java
// 예전: break 빠뜨리면 fall-through 버그
String label = switch (status) {
    case READY -> "결제 대기";
    case PAID, SHIPPED -> "진행 중";            // 여러 값
    case CANCELED -> {
        log.info("취소");
        yield "취소됨";                          // 블록에서 값 반환
    }
};                                               // enum의 모든 경우를 다루면 default 불필요
```

### 텍스트 블록 (15)
```java
String json = """
        {
          "name": "%s",
          "age": %d
        }
        """.formatted(name, age);

String sql = """
        SELECT m.id, m.name
        FROM member m
        WHERE m.grade = :grade
        """;
```

### record (16)
```java
public record OrderResponse(Long id, long amount, OrderStatus status) { }
```

### instanceof 패턴 매칭 (16)
```java
// 예전
if (obj instanceof String) {
    String s = (String) obj;
    System.out.println(s.length());
}
// 이제
if (obj instanceof String s && !s.isEmpty()) {
    System.out.println(s.length());
}
```

### sealed 클래스·인터페이스 (17)
**상속할 수 있는 하위 타입을 제한**합니다.
```java
public sealed interface Payment permits CardPayment, BankTransfer, KakaoPay { }

public record CardPayment(String cardNumber) implements Payment { }
public record BankTransfer(String account) implements Payment { }
public final class KakaoPay implements Payment { }
```
- 하위 타입은 `final`, `sealed`, `non-sealed` 중 하나
- 컴파일러가 **모든 경우를 알기 때문에** switch에서 빠진 경우를 잡아 줌 (아래)

## 3. Java 21 (LTS)

### switch 패턴 매칭 + record 패턴
```java
long fee(Payment payment) {
    return switch (payment) {
        case CardPayment(String number) when number.startsWith("9") -> 0;   // 가드 조건
        case CardPayment c -> 300;
        case BankTransfer(var account) -> 500;                             // record 분해
        case KakaoPay k -> 100;
        // sealed라 모든 경우를 다뤘으므로 default 불필요.
        // 새 결제 수단을 추가하면 이 switch가 컴파일 에러 → 처리 누락 방지
    };
}

// null도 case로
switch (obj) {
    case null -> "null";
    case String s -> "문자열 " + s;
    case Integer i when i > 10 -> "큰 수";
    case Integer i -> "작은 수";
    default -> "기타";
}
```
> sealed + record + switch 패턴 매칭 조합은 **대수적 데이터 타입**처럼 쓸 수 있어, 결과 타입(성공/실패), 이벤트 종류, 명령 처리에 유용합니다.

### 가상 스레드 (Virtual Threads)
수백만 개도 만들 수 있는 **JVM이 관리하는 경량 스레드**입니다. I/O 대기 중에는 OS 스레드를 놓아 줍니다.
```java
try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
    IntStream.range(0, 10_000).forEach(i -> executor.submit(() -> callExternalApi(i)));
}
```
```yaml
# Spring Boot 3.2+
spring.threads.virtual.enabled: true
```
(→ `05.동시성/05.가상스레드.md`)

### Sequenced Collections
순서가 있는 컬렉션에 **공통 메서드**가 생겼습니다.
```java
list.getFirst();   list.getLast();   list.reversed();
list.addFirst(x);  list.removeLast();
linkedHashSet.getFirst();
linkedHashMap.firstEntry();  linkedHashMap.pollLastEntry();  linkedHashMap.sequencedKeySet();
```
> 예전에는 `list.get(list.size() - 1)`, `deque.peekLast()`, `sortedSet.last()`처럼 제각각이었습니다.

### 그 밖의 21 기능
- **Generational ZGC** (세대별 ZGC, 23부터 ZGC 기본 모드)
- `String.indexOf(ch, from, to)`, `StringBuilder.repeat()`, `Math.clamp()`

## 4. Java 22 ~ 25

| 버전 | 기능 | 설명 |
|---|---|---|
| 22 | **이름 없는 변수 `_`** | 쓰지 않는 변수: `catch (Exception _)`, `case Point(var x, _)` |
| 22 | FFM API (Foreign Function & Memory) | JNI 없이 네이티브 코드·메모리 접근 |
| 23 | 마크다운 문서 주석 `///` | Javadoc을 마크다운으로 |
| 24 | **Stream Gatherers** | 사용자 정의 중간 연산 (`windowFixed`, `windowSliding` 등) |
| 24 | **가상 스레드 synchronized 피닝 해결** | synchronized 블록 안에서 블로킹해도 OS 스레드를 붙잡지 않음 |
| 24 | Class-File API | 바이트코드 읽기·생성 표준 API |
| **25** | **Scoped Values** | ThreadLocal보다 안전·가벼운 불변 컨텍스트 전달 (가상 스레드에 적합) |
| **25** | **유연한 생성자 본문** | `super(...)` 호출 **전에** 인자 검증 코드 작성 가능 |
| **25** | **간단한 소스 파일과 인스턴스 main** | `void main() { IO.println("hi"); }` (클래스 선언 생략, 학습용) |
| **25** | 모듈 import 선언 | `import module java.base;` |
| **25** | **Compact Object Headers** | 객체 헤더를 줄여 힙 사용량 감소 (옵션: `-XX:+UseCompactObjectHeaders`) |

```java
// Stream Gatherers (24): 3개씩 묶기
List<List<Integer>> windows = Stream.of(1, 2, 3, 4, 5, 6, 7)
        .gather(Gatherers.windowFixed(3))
        .toList();                                  // [[1,2,3],[4,5,6],[7]]

// 유연한 생성자 본문 (25)
public class PositiveBigInteger extends BigInteger {
    public PositiveBigInteger(long value) {
        if (value <= 0) throw new IllegalArgumentException("양수만");   // super() 전에 검증
        super(String.valueOf(value));
    }
}

// Scoped Values (25)
private static final ScopedValue<String> REQUEST_ID = ScopedValue.newInstance();

ScopedValue.where(REQUEST_ID, "req-123").run(() -> {
    handle();                        // 이 범위 안 어디서든 REQUEST_ID.get() → "req-123"
});                                  // 범위를 벗어나면 자동으로 사라짐 (remove 누락 걱정 X)
```

## 6. 면접 질문

1. **현재 쓰는 자바 버전과 그 버전의 주요 기능은?**
   → 예: Java 21을 쓰며, 가상 스레드로 I/O가 많은 요청을 적은 자원으로 처리할 수 있고, record와 sealed, switch 패턴 매칭으로 데이터 모델과 분기 처리를 안전하고 간결하게 작성합니다.
2. **record와 일반 클래스의 차이는?**
   → record는 불변 데이터 운반용으로 private final 필드, 생성자, 접근자, equals·hashCode·toString을 자동으로 만들며 다른 클래스를 상속할 수 없습니다.
3. **sealed 클래스를 쓰는 이유는?**
   → 상속 가능한 하위 타입을 제한해 도메인 모델을 명확히 하고, switch 패턴 매칭에서 컴파일러가 모든 경우를 다뤘는지 검사해 처리 누락을 막을 수 있기 때문입니다.
4. **LTS 버전이란?**
   → 장기간 보안·버그 수정이 지원되는 버전으로 2년마다 나오며(8, 11, 17, 21, 25), 실무에서는 주로 LTS를 사용합니다.

## 핵심 정리
- LTS: 8 → 11 → **17**(Spring Boot 3·4 최소) → **21** → **25**
- 17까지: `var`, switch 식, 텍스트 블록, record, instanceof 패턴, sealed
- 21: **가상 스레드**, switch·record 패턴(+ sealed로 누락 검사), Sequenced Collections
- 22~25: `_`, Stream Gatherers, 가상 스레드 피닝 해결(24), Scoped Values·유연한 생성자·Compact Object Headers(25)
