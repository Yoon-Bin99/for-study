# JAVA·JVM 스터디 자료

백엔드 면접과 실무에서 필요한 **자바 언어 심화 + JVM + 동시성**을 정리한 자료입니다.

- 기준: **Java 21 (LTS)**, Java 25 변경 사항은 본문에 표시
- 예제 코드는 Java 21에서 컴파일·실행 확인 (Java 22+ 전용 문법 제외)

## 문서 구성

학습 목표 → 개념·동작 원리(그림) → 비교표 → 예제 코드 → 면접 질문 → 핵심 정리
