1. **면접 질문은 소리 내어 답하기**: 문서 끝의 면접 질문을 답변 요약을 가린 채 1분 안에 말해 보세요. 막히는 곳이 약한 부분입니다.
2. **직접 재현하기**: N+1, 트랜잭션 자기 호출, 재고 동시성, 캐시 스탬피드처럼 문제를 다루는 문서는 작은 프로젝트에서 일부러 문제를 만들고 고쳐 보세요.
3. **내 프로젝트와 연결하기**: 실제로 사용한 기술을 문서의 개념과 엮어 "왜 이렇게 설계했는지" 설명할 수 있게 정리하세요.
4. **문서 사이 연결 따라가기**: 본문의 `→ 다른 문서` 표시를 따라가면 같은 개념을 다른 관점에서 볼 수 있습니다. (예: 운영체제 동기화 → 자바 동시성 → JPA 락 → Redis 분산 락)
