# Spring JPA 스터디 자료

백엔드 면접과 실무의 중심인 **스프링 핵심 원리 + JPA**를 정리한 자료입니다.

- 기준: **Spring Boot 3.x / 4.x** (Spring Framework 6/7, Hibernate 6/7, Jakarta Persistence 3.1/3.2)
- 버전마다 다른 부분은 본문에 표시
- 예제는 `com.shop` 패키지의 주문·회원·상품 도메인으로 통일

## 문서 구성

학습 목표 → 개념·동작 원리(그림) → 예제 코드 → 실무 주의점 → 면접 질문 → 핵심 정리
