# 05. 쉘 스크립트 (Bash)

> **학습 목표**
> - 변수, 조건문, 반복문, 함수를 사용한 Bash 스크립트를 작성할 수 있다.
> - 종료 코드와 `set -euo pipefail`로 안전한 스크립트를 만들 수 있다.
> - 간단한 배포 스크립트를 작성할 수 있다.

## 2. 변수

```bash
NAME="myapp"               # = 양옆에 공백 X
echo "$NAME"               # 사용 시 $
echo "${NAME}-v1"          # 이어 붙일 때 중괄호
TODAY=$(date +%Y%m%d)      # 명령어 결과를 변수에 (명령 치환)
COUNT=$((3 + 4))           # 산술 연산

readonly APP_DIR=/opt/app  # 상수
export PROFILE=prod        # 환경 변수 (자식 프로세스에 전달)
```

### 따옴표 차이
```bash
NAME="kim"
echo "Hello $NAME"    # Hello kim        (큰따옴표: 변수 치환 O)
echo 'Hello $NAME'    # Hello $NAME      (작은따옴표: 그대로)
```
> 변수는 **항상 큰따옴표로 감싸세요.** `rm $FILE`에서 FILE에 공백이 있으면 여러 파일로 쪼개져 엉뚱한 파일이 지워질 수 있습니다.

### 특수 변수
| 변수 | 의미 |
|---|---|
| `$0` | 스크립트 이름 |
| `$1`, `$2` ... | 인자 |
| `$#` | 인자 개수 |
| `$@` | 모든 인자 (각각 분리) |
| `$?` | **직전 명령의 종료 코드** |
| `$$` | 현재 스크립트 PID |

### 기본값
```bash
PROFILE=${1:-dev}     # 첫 번째 인자가 없으면 dev
PORT=${PORT:-8080}    # 환경 변수 PORT가 없으면 8080
```

## 3. 종료 코드 (Exit Code)

모든 명령은 끝날 때 **0(성공) ~ 255** 의 종료 코드를 반환합니다. **0이 성공, 0이 아니면 실패**입니다.

```bash
ls /nope
echo $?        # 2 (실패)

# && : 앞이 성공하면 실행, || : 앞이 실패하면 실행
./gradlew build && echo "빌드 성공" || echo "빌드 실패"
mkdir -p /opt/app && cd /opt/app
```

CI/CD 도구(GitHub Actions, CodeBuild)는 **종료 코드가 0이 아니면 단계를 실패**로 처리합니다.

## 4. 조건문

```bash
if [ "$PROFILE" = "prod" ]; then
    echo "운영 배포"
elif [ "$PROFILE" = "stg" ]; then
    echo "스테이징 배포"
else
    echo "개발 배포"
fi
```
> `[` 뒤와 `]` 앞에는 **반드시 공백**이 필요합니다. bash에서는 더 안전한 `[[ ... ]]`도 쓸 수 있습니다.

| 비교 | 문자열 | 숫자 |
|---|---|---|
| 같다 | `=` (또는 `==` in `[[ ]]`) | `-eq` |
| 다르다 | `!=` | `-ne` |
| 크다 / 작다 | | `-gt` / `-lt` |
| 크거나 같다 / 작거나 같다 | | `-ge` / `-le` |
| 비어 있다 / 아니다 | `-z "$A"` / `-n "$A"` | |

| 파일 검사 | 의미 |
|---|---|
| `-f file` | 일반 파일이 존재 |
| `-d dir` | 디렉토리 존재 |
| `-e path` | 존재 |
| `-x file` | 실행 가능 |

```bash
if [ ! -f "app.jar" ]; then
    echo "app.jar가 없습니다" >&2     # 에러 메시지는 stderr로
    exit 1
fi
```

## 6. 함수

```bash
log() {
    echo "[$(date '+%Y-%m-%d %H:%M:%S')] $*"
}

check_port() {
    local port=$1               # local: 함수 안에서만 쓰는 변수
    ss -tln | grep -q ":$port "
}

log "배포 시작"
if check_port 8080; then log "8080 사용 중"; fi
```
- 함수의 반환값은 **종료 코드**(`return 0/1`)입니다. 값을 돌려주려면 `echo`하고 `$(함수)`로 받습니다.

## 7. 안전한 스크립트: set -euo pipefail

```bash
#!/usr/bin/env bash
set -euo pipefail
```

| 옵션 | 의미 |
|---|---|
| `-e` | 명령이 **실패하면 즉시 스크립트 종료** (기본은 실패해도 계속 진행!) |
| `-u` | **정의되지 않은 변수** 사용 시 에러 (`$DIR` 오타 방지) |
| `-o pipefail` | 파이프 중간 명령이 실패해도 실패로 처리 (기본은 마지막 명령 결과만 봄) |

```bash
# set -e 가 없으면?
cd /opt/nope        # 실패
rm -rf ./*          # 현재 디렉토리(엉뚱한 곳)의 파일 삭제!
```

### trap: 종료 시 정리 작업
```bash
TMP_DIR=$(mktemp -d)
trap 'rm -rf "$TMP_DIR"' EXIT     # 스크립트가 어떻게 끝나든 정리
```

## 8. 실전: Spring Boot 배포 스크립트

```bash
#!/usr/bin/env bash
set -euo pipefail

APP_NAME="myapp"
APP_DIR="/opt/${APP_NAME}"
JAR_NAME="${APP_NAME}.jar"
NEW_JAR="${1:?사용법: $0 <새 jar 경로>}"     # 인자가 없으면 에러 메시지 출력 후 종료
HEALTH_URL="http://localhost:8080/actuator/health"

log() { echo "[$(date '+%H:%M:%S')] $*"; }

log "1. 기존 jar 백업"
if [ -f "${APP_DIR}/${JAR_NAME}" ]; then
    cp "${APP_DIR}/${JAR_NAME}" "${APP_DIR}/${JAR_NAME}.bak"
fi

log "2. 새 jar 배치"
cp "$NEW_JAR" "${APP_DIR}/${JAR_NAME}"

log "3. 서비스 재시작"
sudo systemctl restart "$APP_NAME"

log "4. 헬스 체크"
for i in $(seq 1 20); do
    if curl -sf "$HEALTH_URL" | grep -q '"status":"UP"'; then
        log "배포 성공"
        exit 0
    fi
    sleep 3
done

log "헬스 체크 실패 → 롤백"
cp "${APP_DIR}/${JAR_NAME}.bak" "${APP_DIR}/${JAR_NAME}"
sudo systemctl restart "$APP_NAME"
exit 1
```

> 이 스크립트는 재시작하는 동안 서비스가 멈춥니다(다운타임). 무중단 배포는 → `05.CICD/04.배포전략.md`

## 10. 면접 질문

1. **`set -e`를 쓰는 이유는?**
   → bash는 기본적으로 명령이 실패해도 다음 줄을 계속 실행하므로, 실패 시 즉시 멈춰 잘못된 상태에서 이후 명령(삭제, 배포)이 실행되는 것을 막기 위해서입니다.
2. **종료 코드란? CI에서 왜 중요한가요?**
   → 명령의 성공(0)·실패(0 이외)를 나타내는 값으로, CI/CD 도구는 이를 보고 단계의 성공 여부를 판단합니다.
3. **변수를 큰따옴표로 감싸야 하는 이유는?**
   → 값에 공백이나 특수문자가 있을 때 단어가 쪼개지거나 글로브로 해석되는 것을 막기 위해서입니다.

## 핵심 정리
- `#!/usr/bin/env bash` + `set -euo pipefail` 로 시작
- 변수 `"$VAR"`, 기본값 `${VAR:-default}`, 명령 치환 `$(cmd)`
- 종료 코드 0 = 성공, `&&` / `||`
- `[ ]` 공백 필수, 문자열 `=`, 숫자 `-eq -gt`
- 배포 스크립트: 백업 → 교체 → 재시작 → 헬스 체크 → 실패 시 롤백
