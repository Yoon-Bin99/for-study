각 문서는 같은 흐름으로 작성되어 있습니다.

1. **학습 목표**
2. **개념과 동작 원리**: 그림(ASCII)과 표
3. **비교표**: 비슷한 기술끼리 차이

5. **면접 질문**: 질문과 답변 요지
6. **핵심 정리**

## 전체 흐름 한눈에 보기

```
[개발자] git push
   ↓
[CI/CD]  GitHub Actions / CodePipeline: 빌드 → 테스트 → Docker 이미지 → ECR
   ↓
[배포]   ECS 또는 EKS(쿠버네티스): 롤링 / 블루·그린 / 카나리
   ↓
[AWS 인프라 — Terraform으로 코드화]
   Route 53 → ALB(퍼블릭 서브넷) → 컨테이너(프라이빗 서브넷) → RDS·ElastiCache(DB 서브넷)
                                        ↓ 비동기
                                     Kafka / SQS
   ↓
[관측]   Prometheus·Grafana(메트릭) + 로그 수집 + 분산 추적 → 알람
```
