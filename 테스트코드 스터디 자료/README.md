# 테스트코드 스터디 자료

백엔드 개발자가 실무와 면접에서 필요한 **테스트 코드 작성법**을 정리한 자료입니다.

- 기준: **JUnit 5/6 (Jupiter), AssertJ, Mockito 5, Spring Boot 3.x/4.x, Testcontainers 2.x**
- Spring Boot 4에서 바뀐 테스트 모듈·패키지와 `@MockitoBean`, `RestTestClient`, `MockMvcTester`는 본문에 표시
- 예제는 「Spring JPA 스터디 자료」와 같은 주문·상품 도메인을 사용

## 문서 구성

학습 목표 → 개념 → 예제 테스트 코드 → 주의점 → 면접 질문 → 핵심 정리

## 활용 팁

- 진행 중인 프로젝트에 **도메인 단위 테스트 → 컨트롤러 테스트 → Testcontainers 레포지토리 테스트 → 동시성 테스트** 순서로 하나씩 추가해 보세요.
